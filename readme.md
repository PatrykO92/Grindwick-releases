# Grindwick

Grindwick is a 2D top-down online action RPG focused on character progression, exploration and grinding.

## Download

Download the newest version from the [Releases](https://github.com/PatrykO92/Grindwick-releases/releases/latest) page.

1. Download the installer for Windows.
2. Run the downloaded file.
3. Follow the installation instructions.

> Grindwick is currently in development. You may encounter bugs, unfinished content and balance changes.
